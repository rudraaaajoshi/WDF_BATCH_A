PRACTICAL 7 — StudentHub PHP Registration

FILES
- index.php: Registration form, PHP POST handling, server-side validation, and CSV storage.
- students.csv: CSV file where successful submissions are saved.

HOW TO RUN WITH XAMPP
1. Extract this ZIP file.
2. Copy the entire Practical-7 folder into C:\xampp\htdocs\
   The final path should be C:\xampp\htdocs\Practical-7\index.php
3. Open XAMPP Control Panel and start Apache. MySQL is not needed.
4. In Chrome, open:
   http://localhost/Practical-7/index.php
5. Submit a name, valid email, and exactly 10 digits for the phone number.
6. After success, open students.csv in the Practical-7 folder to see the saved record.

IMPORTANT
- Do not open index.php by double-clicking it. PHP must run through localhost/XAMPP.
- If you still see 404, confirm the folder is directly inside C:\xampp\htdocs\ and the filename is index.php.
- The CSV file contains personal information; do not publish it online.
